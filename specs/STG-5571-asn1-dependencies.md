# STG-5571: совместимые ASN.1 зависимости CLI

CLI фиксирует pyasn1 0.4.8 и pyasn1-modules 0.2.8, поэтому resolver не может
установить исправленные версии в монолит. Код CLI не использует их напрямую;
они нужны google-auth/rsa. Обновить обе версии совместно до pyasn1 0.6.5 и
pyasn1-modules 0.4.2, сохранить остальные зависимости и поведение магазинов.

Проверка: обычная установка зависимостей без --no-deps, pip/uv check,
RSA PKCS#1 encode/decode и google-auth credentials с синтетическим ключом,
полный pytest CLI и security gate, сборка wheel с теми же requirements.
Новая версия только после успешной проверки, чтобы не менять опубликованный
2026.11.5. Production-учётные данные, live-магазины и активные ветки другого
чата не меняются.
