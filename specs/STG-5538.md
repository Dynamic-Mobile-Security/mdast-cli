# STG-5538: исправление Trivy Image в SAP helper

## Проблема

После merge Markea !90, прошедшего MR CI 313677, pipeline main 313697 собрал образ и остановился на Trivy Image job 1698176. Найдено 5 HIGH в mdast-sap-linux-amd64 из CLI 2026.11.1: четыре stdlib Go 1.27.1 и одна klauspost/compress 1.18.6. Python-зависимости после согласованного обновления прошли проверку. Доставка Markea не прошла этот gate.

## Предлагаемое изменение

1. Сохранить ipatool v2.7.0 и Apple-протокол. Закрепить минимальную исправленную klauspost/compress 1.18.7 с проверкой module checksum в сборке helper.
2. Обновить только два go-version pin в .github/workflows/tests.yml и python-publish.yml с 1.27.1 до 1.27.3. Изменение двух pin CI отдельно согласовано пользователем 05.11.2026.
3. Собрать и проверить все шесть helpers, выполнить полный набор тестов CLI, kbsync smoke и Trivy по готовому Linux-бинарнику. Выпустить CLI 2026.11.2 через новый PR после зелёного CI.
4. Создать связанную задачу и новые ветки STG-<номер>, сохранив историю уже смерженных MR. Подготовить follow-up MRs с pin CLI 2026.11.2 в монолите и hash-pinned wheel в Markea, bump версии Markea. Merge только после проверки CI на точном SHA.
5. Проверить Trivy готового образа Markea после сборки. Не обходить Trivy, не менять инфраструктуру и не запускать ручной deploy.

## Критерии приёмки

- Trivy готового SAP helper и образа Markea: 0 HIGH/CRITICAL.
- Пакет воспроизводимо содержит все шесть helper-артефактов, исходный upstream проверен по checksum, изменение Go-модуля явно закреплено.
- Unit/contract/security tests CLI и штатные MR CI потребителей успешны.
- Реальная генерация kbsync и проверка App Store загрузки на Linux проходят в изолированном каталоге.
- CLI выпущена новым неизменяемым номером; существующие релизы и MR не переписываются.

## Границы

Текущий релиз 2026.11.1 функционально проверен четырьмя IPA-загрузками, но готовый helper не проходит security gate образа Markea. В готовность доставки это не засчитывается. Отдельный запуск Base более не нужен: существующая Base job 1698102 успешна. Pipeline монолита 313674 остаётся отменённым.
