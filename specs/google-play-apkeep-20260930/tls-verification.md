# Проверка TLS macOS, 01.10.2026

Кандидат CLI 2026.10.2 / apkeep 1.0.0-sting.3. Проверка macOS выполнена на ARM Mac: ARM64 нативно, x86_64 через Rosetta.

## Причина и изменение

У gpapi 6.1.0 включён reqwest native-tls-no-alpn. Через объединение Cargo features это выбирает native-tls для gpapi и загрузчика APK. На проверяемом Mac native-tls возвращает errSSLBadCert (-9808) на HTTPS Google. Минимальный клиент с rustls и включённой проверкой доверия получает ожидаемые ответы с тех же адресов.

Native-tls оставлен для платформ кроме macOS. macOS использует штатный rustls reqwest с системной проверкой доверия. Для gpapi сохранён HTTP/1.1 поверх HTTPS: при HTTP/2 Google отклоняет его запрос авторизации с PROTOCOL_ERROR. Python-зависимости, в том числе cryptography, не менялись. Linux сохраняет прежний native TLS и создание клиента.

## Уже проверено

- 333 теста CLI прошли без пропусков; 20 security-тестов успешны.
- Настоящие macOS ARM64 и x86_64 бинарники отклоняют недоверенный сертификат локального HTTP CONNECT proxy до отправки HTTP-запроса с credentials. По два сценария на архитектуру: OAuth и скачивание с AAS.
- 20/20 реальных загрузок на macOS: ARM64/x86_64, напрямую/через SOCKS5 с аутентификацией. В каждом сочетании проверены Calculator, Firefox, VLC, Wikipedia и целевое приложение.
- Размеры: 4 850 520; 123 060 322; 43 499 174; 27 127 132; 44 901 269 байт. Везде проверены CRC и AndroidManifest, native ABI у четырёх приложений x86_64, Calculator без native-библиотек.
- Для macOS использован локальный SOCKS5, передающий настоящие HTTPS-соединения к Google. Зафиксировано 70 соединений на порт 443. Прямой TCP с Mac к Mobix origin недоступен; origin проверяется отдельно с разрешённого dev.
- OAuth-получение свежего AAS вживую не проверялось: предоставлены email и готовый AAS, OAuth-token отсутствует. Передача параметров и ошибки OAuth проверены тестами.

## Оставшиеся проверки

Оба Linux-бинарника собраны с cargo --locked и проверены как статические. Linux ARM64 прошёл реальные загрузки Calculator и Firefox. В wheel/sdist проверены SHA256 четырёх apkeep и executable mode; все шесть SAP helpers сохранены, Python Requires-Dist совпадает с CLI 2026.10.1. Все 349 записей зависимостей Cargo.lock сохранены, меняется только ревизия apkeep.

Linux x86_64 на dev: 10/10 загрузок тех же пяти приложений, через настоящий Mobix SOCKS5 и напрямую. Проверены размеры, CRC, AndroidManifest и ABI. Кандидат запускался во временном каталоге без установки поверх пакетов dev; файлы удалены. Всего 32 успешные реальные загрузки для этой ревизии.

Остаётся обязательный CI PR. До его завершения кандидат не публикуется и на стенды не доставляется.
