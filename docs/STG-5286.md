# STG-5286: завершение CLI после отмены скана

## Проблема

В микросервисном режиме CANCELLED/COMPLETE не считается конечным состоянием. До старта CLI пишет Scan did not start, после старта ждёт таймаут.

## Ожидаемое поведение

- CANCELLED/COMPLETE завершает ожидание сразу с существующим SCAN_FAILED (5) и сообщением об отмене.
- Отмена не запускает остановку ручного скана или загрузку отчётов.
- CANCELLED с промежуточным статусом допускается в ожидании, но не считается успехом.
- SUCCESS/COMPLETE, SUCCESS/PARTIAL_COMPLETE, FAIL/FAIL, промежуточные состояния и режим монолита сохраняют поведение.
- Обработать отмену до старта, после WORKING и при восстановлении ответа на start.

## Проверка

Unit и mocked HTTP CLI сценарии до/после старта, manual и auto, промежуточная отмена, оба штатных режима CLI. Живые проверки выполняются только на dev. Доставка на prod исключена по указанию пользователя 17.11.2026.
